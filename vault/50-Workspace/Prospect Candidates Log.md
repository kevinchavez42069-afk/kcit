# Prospect Candidates Log

Every business `prospect-scout` evaluates, accepted or rejected, one line
each. Not written for Kevin to read routinely, it's the agent's own memory
so a later run (especially an unattended scheduled one) doesn't re-spend
WebSearch budget re-evaluating a business already checked. Rejected doesn't
mean permanently excluded, a business's web presence can change, so treat
anything logged more than roughly 90 days ago as fair game to re-check.

**Format:** `- YYYY-MM-DD — Business Name — accepted [[link]]` or
`- YYYY-MM-DD — Business Name — rejected: one-line reason`
