Context worth knowing

This is the second version of this map
The original (2026-09-06) covered four views of the kc.IT product and one phase-4 confirm-step diagram, before the agent fleet grew from three agents to six, before the dashboard was rebuilt twice, and before the 2026-09-07 infrastructure audit. This version folds all of that in rather than appending a fifth and sixth view onto the old one.
The audit this map cross-references
See the full 2026-09-07 infrastructure and strategy audit for the complete findings, severity ratings, and the prioritized fix list behind every red element on this page.
What changed since the last map
developer and code-reviewer joined the fleet (phase 7). The dashboard was reskinned twice and rebuilt around a persistent EA chat, a collapsible drawer for the other five agents, and a live Fleet tab (phases 8 and 9). An explicit, session-only auto-approve toggle was added, then patched so scheduled runs can never inherit it (phases 9 and 9.1). None of this changed the underlying kc.IT product, which is why views 1 and 4 carry over the most.
Why the exposed API key from the audit doesn't appear as its own node here
It was a file left on disk, not a structural feature of the system, there's nothing architectural to draw. It's called out in the audit itself; treat it as already handled rather than a live diagram element.
